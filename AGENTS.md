# KIRO Platform

Образовательная платформа с расписанием, теорией, заданиями и библиотекой. Фронтенд на React и Vite находится в `src/`. API на Express и SQLite находится в `backend/`, админ-панель — в `backend/admin/`.

## Локальный запуск

- Фронтенд на порту 5173: `npm run dev -- --port 5173 --strictPort`.
- API на порту 3001: `npm --prefix backend run dev`. Vite проксирует запросы к `/api` на этот порт. Проверка API: `http://localhost:3001/health`.
- Предпросмотр на порту 4173: выполните `npm run build`, затем `npm run preview -- --port 4173 --strictPort`.

## Соглашения проекта

- Именуйте компоненты React в PascalCase, функции в camelCase, CSS-классы в формате `block-element`. Для новых ключей localStorage используйте префикс `kiro_`.
- Сохраняйте префикс `/api/` для маршрутов API. В админ-панели придерживайтесь существующих шаблонов имён `load…`, `open…Modal`, `save…` и `delete…`. Начальные данные SQLite находятся в `backend/src/db.js`.
- При изменении расписания, библиотеки и заданий сохраняйте действующие правила доступа по дате и нумерацию дней. Уточняйте актуальное поведение по коду. Исторический контекст описан в `PROJECT_CONTEXT.md`.

## Проверки изменений

- Для изменений фронтенда выполните `npm run build` и проверьте затронутый сценарий. Для изменений API проверьте затронутые маршруты на локальном сервере.
- Для экспериментов с миграциями и изменением данных SQLite используйте отдельную копию базы. Сохраняйте пользовательские правки. Коммиты, отправку в удалённый репозиторий и деплой выполняйте по запросу пользователя.
